# 1.0.7 回归与验收

## 离线自检

```powershell
./dist/AirStereo.exe selftest
./dist/AirStereo.exe language-selftest
```

自检覆盖十段 EQ、启动路线、中文/英文文本、编译型界面加载、语言切换、设置保留、托盘停止/退出和安装器关闭路线。它不连接真实音响，也不证明实际网络同步或听感。

## 设备与音频

- 多个独立音响中选 0 只禁止播放；只选 1 只完整立体声且平衡禁用；选 2 只按顺序 L/R，第三只被拒绝。
- 原生配对作为一个逻辑目标；不完整信息不误判为确认配对，成员不重复选择。
- 双独立音响任一掉线停止整组；重连开关关闭不重试，开启按 1–10 次上限恢复完整组合。
- ALAC/PCM 与 44.1/48 kHz 分别验证接收端协商、暂停/恢复、长时间播放、左右一致性和中断恢复。
- 播放期间音量、十段 EQ、预设、旁路和平衡保持可用；延迟、编码和采样率锁定。不存在左右测试音/校准入口。
- 手动音量拖动后点击 ✓，实时音量拖动直接应用；Windows 10 图标可见，重复点击不漂移。
- 主动停止不产生正常拆连故障；网络不可用与真实播放错误记录故障，空扫描显示未发现音响。

## 界面、启动与资源

- 系统/浅色/深色即时生效，高对比度可读；首次打开和托盘重开无白色闪烁或白边。
- 100%、125%、150%、175%、200% DPI 和大字体下无重叠，下拉选项从控件下方展开。
- 打开设置、点击桌面、关闭设置后仍可点击桌面收回托盘；设置保持可调整大小，初次居中。
- 退出关闭设置；托盘停止播放仅停止音频。
- 启动自动连接上次完整目标，开机自启/静默配置保留；Windows 策略禁止启动时明确提示。
- 中文/英文切换覆盖托盘、设置、通知和右键菜单，并保持用户设置。
- 对比启动、空闲、设置打开/关闭和连续播放的工作集、私有内存、线程、句柄；区分 GC 波动与持续增长。

## 安装与发布

- MSI 中文向导、路径选择、记忆原路径、1.0.6 升级、运行中占用处理、卸载清理分别实测。
- MSI、应用、MSIX、文档版本一致；MSIX 使用正确商店身份和四段版本。
- PRI 中路径均存在，编译 XAML 保留；MakeAppx 解包逐文件哈希一致。
- 发布资产不含日志、配置、凭据或私钥；GitHub latest/tag/源码及公开下载 SHA-256 一致。
- Store 版更新走商店；独立版检查 GitHub 正式 Release，高版本可打开发布页面，失败时 UI 保持响应。
