# 回归与验收

本版自动测试 325 项通过、0 项失败。离线 HTTP 桩、合成设备数据和模拟 DPI 检查不能替代实体硬件验收。

## 手动验收清单
- 多只独立音响扫描后，0 只选择时禁止播放；只选其中 1 只时完整立体声、平衡禁用。
- 勾选两只独立音响时按顺序显示 L/R，共用时间线/时钟；第三只被拒绝。反向重新勾选应换左右。
- 原生立体声对显示一个逻辑目标、成员不可重复选择；信息不完整或仅名称相近不误认为已确认配对。
- 双设备任何成员掉线应整体停止且提示掉线成员，不静默降级。
- 播放中修改 EQ、平衡、音量、延迟并测试左右；测试时绕过平衡，结束后恢复；单设备与原生配对测试完整声道。
- 反复勾选不收缩弹窗；设置四页与均衡器在真实 100%、125%、150%、200% 系统 DPI 下不遮挡、不黑白混杂。
- 无故障时导出禁用且点击不会打开保存框；有故障时查看、取消导出和导出均正常。安装目录不可写时回退存储。
- 设置 → 常规 → 检查更新：等版本无需更新；更高正式版本可打开发布页面；断网/超时/限流提示失败；检查时 UI 仍可操作。
- 安装后运行、退出托盘、覆盖安装、开机自启和卸载行为应由用户在目标系统确认。

发布前还需验证安装包资源、解压后的文件哈希、内置运行时与安装后自检。测试安装使用隔离目录，不更改当前用户已有安装或音响设置。
