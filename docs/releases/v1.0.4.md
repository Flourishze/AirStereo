# AirStereo 1.0.4

Windows x64 · 2026-10-05（Asia/Shanghai）

AirStereo 将 Windows 系统播放声音通过局域网发送到兼容的 AirPlay 音响，支持独立单音响、自选双音响 L/R 和原生立体声对。

## 本版改进
- 为采集与重采样缓冲设置上限，限制异常大块输入造成的内存膨胀。
- 滚动日志截断时清理撤销历史，减少长时间运行的诊断内存占用。
- 修复首次打开托盘设备窗口后点击桌面无法自动收回的问题。
- 保留设置与均衡器打开时的窗口保护，收起控制窗口不影响播放。
- 保留高 DPI、大字体适配，以及 EQ、音量、平衡、左右测试音、延迟与故障目录功能。

## 下载与安装
- `AirStereo-Setup-1.0.4-x64.exe`：普通 Windows 安装向导，支持记忆上次安装路径。
- `AirStereo-1.0.4-x64.msi`：MSI 安装包，支持从旧版 MSI 升级。
- `AirStereo-1.0.4-x64.msix`：未签名的微软商店提交包；普通用户请通过 Microsoft Store 安装商店签名版本。
- `AirStereo-1.0.4-Source.zip`：应用源码、文档与构建打包脚本。
- `SHA256SUMS.txt`：下载文件的 SHA-256 校验值。

EXE/MSI 内置 .NET Core / Desktop 10.0.12。安装或升级前从托盘菜单退出旧版。不要同时运行独立安装版与商店版。

## 使用方式
1. 点击右下角 AirStereo 托盘图标，扫描并勾选音响。
2. 一只独立音响播放完整立体声；两只独立音响按勾选顺序分配 L/R，共用时间线与 PTP 时钟。
3. mDNS 明确识别的原生立体声对作为一个逻辑目标，由接收端分配物理左右声道。
4. 点击播放发送电脑声音；点击桌面收回窗口，点击托盘图标重新展开。
5. 设置中可调整音量、平衡、EQ 与左右测试音；延迟在停止后调整，下次播放生效。

## 兼容性与更新
适用于 Windows 10 22H2 及更新的 Windows x64 系统。实际 AirPlay 兼容性与同步效果取决于音响固件、网络和访问权限。
EXE/MSI 使用本仓库正式 Releases 检查更新；商店版由 Microsoft Store 管理更新。

## English
AirStereo sends Windows system audio to compatible AirPlay speakers over the local network. Version 1.0.4 bounds capture and resampling buffers, clears discarded log undo history, and restores automatic dismissal of the tray panel on first launch. Existing single-speaker stereo, independent L/R speakers, native stereo pairs, EQ and audio controls are retained.

Use the EXE installer or MSI for a standalone installation. The unsigned MSIX is for Store submission; end users should install the Store-signed app through Microsoft Store. Exit the old tray application before upgrading. AirStereo code and documentation are MIT licensed; third-party components retain their own licenses.
