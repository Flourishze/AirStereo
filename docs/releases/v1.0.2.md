# AirStereo 1.0.2

Windows x64 · 2026-10-02（Asia/Shanghai）

## 本版重点
- 主动停止播放时先标记会话关闭，避免正常 TEARDOWN 被误记为连接或同步故障。
- 原生立体声对的两个成员统一关闭，减少停止过程中的连带误报。
- 意外 Event channel 断开会记录具体音响名称和网络地址。
- 故障页改为“打开故障文件夹”，直接进入实际 Diagnostics 存储目录，不再使用保存文件对话框。
- 目录不存在时自动创建；安装目录不可写时使用用户本地备用目录。
- 保留单设备、双设备 L/R、原生立体声对、EQ、平衡、测试音、延迟和检查更新。

## 下载内容
- `AirStereo-Setup-1.0.2-x64.exe`：Windows x64 安装包。
- `AirStereo-1.0.2-Source.zip`：源码、文档、构建和打包脚本。
- `SHA256SUMS.txt`：发布资产校验值。

安装前请退出旧版托盘程序，可选择原目录覆盖安装。发布前已确认指定 GitHub 仓库为公开仓库，更新检查继续使用该仓库的正式 Releases。

## 验证说明
安装界面、卸载列表和应用版本统一为 1.0.2；打包脚本会拒绝与应用版本不符的包。按用户要求未运行本版自动或实体设备测试，仅核对编译、版本及打包资产，不沿用旧版测试结论。
本版本基于现有 AirStereo 音频链路增量修改，未复制第三方软件源码或私有实现。真实音响连接和停止流程请在目标机器上验收。
