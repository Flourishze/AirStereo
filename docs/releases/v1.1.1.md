# AirStereo2 1.1.1

## 本版更新

- **架构精简与体积优化**：精简运行架构为轻量化双进程（`AirStereo2.exe` + `AirStereo2.Engine.exe`），移除冗余运行组件，MSI 安装包体积由 74.2 MB 缩减至 **51.3 MB**，启动更快、资源占用更低。
- **音频引擎与时钟同步增强**：
  - 升级音频引擎 `AirStereo2.Engine.exe`，新增 AirPlay 2 BMCA PTP 从时钟协商与 8 Hz 紧耦合时钟漂移回归，显著提升 HomePod 立体声对同步精度与稳定性。
  - 新增自适应 PTP 播放缓冲（Adaptive Playout Lead）与丢包重传（RTX）平滑调节机制，网络抖动丢包时自动柔和增大缓冲，稳定后自动平滑回落至低延迟基线。
  - 新增 **44.1 kHz / 48 kHz 输出采样率**与协议模式选择（自动推荐 / AirPlay 1 / AirPlay 2），支持冷启动配置持久化；全新安装默认采用 `ALAC` 无损编码，HomePod 开箱即连。
- **防火墙修复与诊断日志升级**：
  - 防火墙修复改用 Windows 原生 COM 接口直接更新规则（不再调用外部脚本），提权后快速清理旧阻止规则并重建 UDP + TCP 放行规则，减少安全软件误报。
  - `service.log` 新增 **4 MB 轮转 / 8 MB 总上限**控制；实时诊断日志与导出的故障报告按界面语言自动转换时区（中文为北京时间 `+08:00`，英文为 `UTC`），并清理实时日志中的 ANSI 控制字符。
- **界面打磨与问题修复**：
  - 主弹窗播放控制区重构为双行分层布局（协议微徽章 + 编码/采样率规格），视觉更清爽；设置窗口整理为 5 个分类页并支持自由缩放与记忆尺寸。
  - 优化 AirPlay 1 模式下连接不支持设备（如 HomePod）的错误响应速度，由原先 45 秒超时缩短至约 2 秒内即时弹窗提示。
  - 修复提示 PCM 编码不受支持并选择取消后，再次点击连接卡住失败的问题，并修复一处极偶发的冷启动设备列表并发竞态。
  - 「关于与更新」新增应用内下载、SHA-256 校验与一键覆盖升级，并在问题反馈旁新增「请作者喝茶」支持入口。

## English

- **Streamlined architecture & smaller installer**: Consolidated into a lightweight two-process layout (`AirStereo2.exe` + `AirStereo2.Engine.exe`), trimming the self-contained MSI installer from 74.2 MB down to **51.3 MB** with faster startup and lower overhead.
- **Upgraded audio engine & PTP synchronization**: Added AirPlay 2 BMCA PTP slave negotiation, 8 Hz tightly-coupled clock-drift regression, adaptive PTP playout lead with smooth RTX recovery, selectable **44.1 / 48 kHz** output sample rates with cold-start persistence, protocol mode selector (Auto / AirPlay 1 / AirPlay 2), and `ALAC` as the default lossless codec for fresh installs.
- **Native COM firewall repair & improved diagnostics**: Repaired Windows Firewall rules directly through native Windows COM APIs (no external scripts) to reduce antivirus false positives; added **4 MB rotation / 8 MB cap** for `service.log`, ANSI cleanup in live logs, and language-aware timestamps (`UTC` for English, `+08:00` for Chinese).
- **UI polish & bug fixes**: Two-line protocol badge + format layout on the playback card, resizable 5-tab Settings window with persisted size, fast (~2 s) AirPlay 1 incompatibility prompts on HomePod instead of 45 s timeout, fixed retry after declining PCM-to-ALAC switch, fixed a rare cold-start discovery race, in-app SHA-256 verified updater, and a "Buy me a tea" support button in About & Updates.
