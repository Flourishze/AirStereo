# AirStereo 1.0.8

本版聚焦扫描优化，沿用现有界面和功能。

## 本版改进

- 优化多网卡扫描逻辑，逐个可用 IPv4 网卡发送 mDNS 查询，修复仅有线连接时可能无法发现 AirPlay 音响的问题。
- 改进启动诊断文件的存储与异常记录，日志写入失败时自动回退到可写用户目录。

## English

Version 1.0.8 focuses on discovery improvements and retains the existing interface and features. mDNS queries are sent through each active IPv4 adapter, fixing cases where speakers could not be discovered over Ethernet with multiple network adapters. Startup diagnostics also use writable user directories with fallback handling.

Use the MSI to install or upgrade on Windows x64 build 19045 or later. Runtimes are included. The Source ZIP matches the v1.0.8 tag, and SHA256SUMS verifies both downloads. The Store edition is installed and updated through Microsoft Store; MSIX is used only for Store submission. No EXE installer is included.
