# AirStereo 1.0.5

Windows x64 · 2026-10-07（Asia/Shanghai）

## 本版改进

- 默认使用原生 ALAC 无损编码（44.1/48 kHz、双声道、16-bit、352 帧/包），在诊断日志和托盘连接状态中显示当前编码；`--pcm` 仅作为实验性回退开关。
- 静音期间继续发送媒体包并推进 RTP 时间线，默认使用 `repeat-last` 静音帧；连续确认源静音达到 90 分钟后执行优雅断开。`--silence-mode=zero` 仅用于实验比较。
- 修复无音频源时采集等待造成的发送落后、跳帧和静音期意外停发。
- 新增“串流时静音本机输出”，默认关闭。启用后持续保持本机静音，停止串流时恢复开始前的静音状态。
- 新增“启动时自动连接”，默认关闭；支持全局开关和按设备选择。
- 改进诊断日志自动跟随：查看历史日志时暂停跟随，停止操作 10 秒后恢复到最新日志。
- 保留既有设备路由、PTP、重传、EQ、测试音、高 DPI 布局与双设备会话语义。

## 下载与安装

- `AirStereo-Setup-1.0.5-x64.exe`：Windows x64 安装向导，适合一般用户。
- `AirStereo-1.0.5-x64.msi`：MSI 安装包，保留既有 UpgradeCode，适合部署。
- `AirStereo-1.0.5-Source.zip`：与 `v1.0.5` 标签一致的应用源码、文档和构建脚本。
- `SHA256SUMS.txt`：上述三个下载文件的 SHA-256 校验值。

EXE/MSI 内置匹配的 .NET Core/Desktop 运行时，无需另外安装 .NET，并附带 `LibALAC64.dll` 及其许可证文本。安装或升级前请从托盘退出旧实例；不要同时运行独立安装版与商店版。
Microsoft Store 版本由商店管理安装和更新。本次 GitHub Release 不提供未签名 MSIX。

## 验证与已知限制

- 离线 SelfTest（含 UiRegressionTests）通过：714 checks，0 failures。覆盖 ALAC 编解码、magic cookie、变长包与重传、采集饥饿保护及界面回归。
- 离线测试不等同于真实音响兼容性、实际安装升级、WACK 或 Microsoft Store 认证。设备固件、访问权限和局域网环境会影响实际连接、同步和播放效果。

## 使用提示

`--pcm`、`--silence-mode=zero` 等参数为实验/回退选项，不作为正式 UI 编码选择。当前默认 ALAC，可在诊断日志和连接托盘状态确认编码。
