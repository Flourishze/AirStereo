# AirStereo 1.0.3

Windows x64 · 2026-10-02（Asia/Shanghai）

## 本版重点
- 修复 150%、175% 和 200% DPI 下设置窗口控件压缩、重叠和文字裁切问题。
- 设置页面按实际 DPI 与字体重新计算布局，并支持纵向滚动；切换页面自动回到顶部。
- 修复重复打开设置后布局高度不断增加的问题。
- 播放期间延迟控件保持可读，仍然锁定不可修改，避免系统禁用色导致文字难以辨认。
- 继续保留单设备完整立体声、双独立设备 L/R、原生立体声对、EQ、平衡、测试音、音量、故障记录和检查更新。
- 安装器继续支持记忆上次安装目录，安装界面、卸载注册和应用版本统一为 1.0.3。

## 下载内容
- `AirStereo-Setup-1.0.3-x64.exe`：Windows x64 安装包。
- `AirStereo-1.0.3-Source.zip`：源码、文档、构建和打包脚本。
- `SHA256SUMS.txt`：发布资产校验值。

安装前请退出旧版托盘程序，可选择原目录覆盖安装。更新检查使用本仓库的正式 Releases。

## 安装与兼容性
安装包内置 .NET Core / Desktop 10.0.12 运行时，适用于兼容该运行时的 Windows x64 系统。AirPlay 连接与同步取决于接收端固件、网络和访问权限。
