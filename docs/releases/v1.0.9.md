# AirStereo2 1.0.9

## 本版更新

- **新增 AirPlay 1 连接支持**：现在可同时连接局域网内兼容 AirPlay 1 与 AirPlay 2 的音响及 Apple 原生立体声对。
- **新增系统音量同步功能**：支持将 Windows 系统音量键/滑块实时同步到 AirStereo2，并改进串流期间的本机输出静音体验。
- **新增网络检测与防火墙修复**：设置 → 故障信息页支持一键检查设备网络连通性、修复 Windows 防火墙规则及导出故障诊断日志。
- **交互与安装体验优化**：完善被其他设备接管播放时的提示与快速重连、默认音响勾选自动连接、延迟缓冲挡位调整、代理/VPN 环境下的检查更新，以及覆盖安装体验。

## English

- **AirPlay 1 support**: Stream audio to both AirPlay 1 and AirPlay 2 speakers, including native Apple stereo pairs.
- **System volume sync**: Sync Windows system volume controls directly to AirStereo2, with improved local output muting while streaming.
- **Network check & firewall repair**: Check local speaker reachability, repair Windows Firewall rules, and export diagnostic logs directly from Settings.
- **Usability & installer improvements**: Added external takeover alerts, selectable default speakers for auto-connect, refined latency tiers, proxy/VPN-friendly update checks, and an upgraded in-place MSI installer.
