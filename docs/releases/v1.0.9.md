# AirStereo2 1.0.9

AirStereo2 1.0.9 带来全新的 AirPlay 1 / AirPlay 2 立体声投送体验、外部设备抢占感知、系统音量同步与本机实时静音守护，以及全面升级的覆盖安装向导。

## 本版亮点与改进

### 播放与音频体验
- **AirPlay 1 / AirPlay 2 全面支持**：支持单只音响立体声、多音响同步播放以及 Apple 原生立体声对（HomePod / HomePod mini）。
- **延迟缓冲五档可调**：提供 `自动`、`标准 · 200 ms`、`均衡 · 300 ms`、`稳定 · 500 ms`、`自定义（0–1000 ms）`，并在播放控制卡片展示实测延迟与 `ALAC / PCM · 44.1 kHz` 编码标注。
- **十段均衡器**：保留竖向十段 EQ 与内置风格预设，调整即时生效，关闭后完全旁路。
- **系统音量同步 + 本机实时静音守护**：新增“系统音量自动同步到 AirStereo2”；开启“串流时静音本机输出”后，调整系统音量约 0.5 秒自动重新静音，停止播放后恢复原静音状态。

### 交互与稳定性
- **外部设备（iPhone / iPad 等）抢占检测与托盘提示**：音响被其他设备接管时自动暂停电脑无效串流，播放控制卡片切换为接管状态并提供 **“立即抢回连接”** 与 **“停止等待自动恢复”**，同步弹出一次 Windows 托盘通知（设置页支持通知开关）。
- **启动自动连接默认音响可视化选择**：设置页直接展示已发现音响与已保存目标列表，支持自由勾选、刷新与启动二次重试。
- **托盘增强与窗口清理**：托盘图标实时跟随系统深浅色切换；悬停显示当前播放目标与音量；右键支持“快速连接音响” / “停止播放”；修复后台隐藏窗口出现在 `Alt+Tab` 的问题。
- **故障诊断、网络/防火墙体检与检查更新**：支持导出故障诊断报告、检查设备网络与修复 Windows 防火墙规则；内置 GitHub Release 检查更新并优化代理/VPN 环境下的获取可靠性。

### 安装包升级
- 全新 MSI 独立安装包支持检测本机已安装版本并提示覆盖更新、自动记住原安装路径、安装前自动优雅关闭运行中的实例、展示 MIT 许可协议、配置用户数据目录可写权限，并在完成页提供透明底色的“立即启动 AirStereo2”勾选项。

## English

AirStereo2 1.0.9 introduces full AirPlay 1 / AirPlay 2 streaming with native Apple stereo pair support, external device takeover detection (e.g. iPhone/iPad) with tray alerts and one-click reclaim, Windows system volume sync, real-time local mute guarding (~0.5 s re-mute after volume adjustments), five latency buffer tiers (`Automatic`, `200 ms`, `300 ms`, `500 ms`, `Custom`), a visible default-speaker checklist for launch auto-connect, built-in network/firewall diagnostics, a proxy/VPN-friendly GitHub update checker, and an upgraded in-place MSI installer.

Use `AirStereo2-1.0.9-x64.msi` to install or upgrade on Windows 10 22H2 (build 19045)+ / Windows 11 x64. All required runtimes are bundled.
