# AirStereo 1.0.1

Windows x64 · 2026-10-01（UTC）

## 本版重点
- 新增“设置 → 常规 → 检查更新”，依托本仓库正式 Releases。
- 修复无故障信息时导出操作不必要地打开保存对话框；无记录时禁用导出。
- 修复设备勾选时弹窗高度收缩，整合深色设置、开机自启及本地故障查看/导出。
- 保留 EQ、平衡、测试音、单设备完整立体声、自选双设备 L/R 与原生配对链路。
- 内置 .NET Core / Desktop 10.0.12，启动器优先使用安装目录内运行时。

## 下载内容
- `AirStereo-Setup-1.0.1-x64.exe`：安装包。
- `AirStereo-1.0.1-Source.zip`：应用源码、文档、构建和打包脚本、安装器二进制模板；不含用户设置、日志或凭据。
- `SHA256SUMS.txt`：上述资产的 SHA-256 校验值。

安装前请先退出旧版托盘程序。可选择原目录覆盖安装；不要同时运行两个版本。

## 验证与已知限制
离线自检 325 项通过、0 项失败；覆盖更新版本解析、HTTP 响应/超时和模拟 DPI 回归。实际音响与真实系统 DPI 仍需用户验收；本次不声称完成新的实体设备测试。

更新功能仅检测正式版本并打开下载页面，不自动下载安装。无联网或 GitHub 限流时会显示检查失败，不把失败当作最新版本。

应用源码完整提供，既有 .NET 安装向导原始源码未保留，当前继续使用明确标注的二进制模板。当前尚未声明开源许可证。
