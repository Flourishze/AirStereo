# AirStereo 1.0.6

AirStereo 将 Windows 系统声音通过局域网发送到兼容 AirPlay 的音响，提供托盘选音响、双设备 L/R、原生立体声对与均衡器功能。

## 安装包图标修正（r2）

统一安装文件、安装窗口与应用的新图标；程序版本仍为 1.0.6，音频程序、MSI 和商店 MSIX 不变。

Installer revision r2 refreshes the setup executable and wizard icons. The app remains version 1.0.6; application payload, MSI and Store MSIX are unchanged. Use AirStereo-Setup-1.0.6-x64-r2.exe for the corrected installer.

## 本版改进

- 新增实时音量调整开关：关闭时拖动后点击 ✓ 应用，开启时拖动即自动应用；默认保留手动模式。
- 新增跟随系统、浅色和深色外观，统一卡片式设置、原生下拉框、按钮和轻量动效。
- 更新应用图标和透明背景托盘图标，优化刷新按钮、均衡器对齐、紧凑布局与大字体显示。
- 修复下拉框悬停后蓝条累积的问题，改进缓冲绘制并保留原生选择与键盘操作。
- 简化独立音响列表提示；扫描无结果作为状态显示，网络不可用、连接失败和播放中断仍记录故障。
- 优化辅助控制连接关闭的提示分类，保留诊断日志，避免将单独的控制通道关闭误判为播放故障。
- 修复 ALAC magic cookie 缓冲区容量未初始化导致的编码器初始化失败。
- 保留单设备、自选双设备、原生立体声对，以及 EQ、平衡、测试音和延迟设置。

## 下载与安装

- AirStereo-Setup-1.0.6-x64-r2.exe：推荐安装向导，修正安装文件与安装窗口图标，保留上次安装路径。
- AirStereo-1.0.6-x64.msi：Windows Installer 安装包，沿用既有 UpgradeCode。
- AirStereo-1.0.6-Source-r2.zip：本版本源码、图标、文档及修正后的打包脚本。
- SHA256SUMS-r2.txt：修正版下载文件与原始资产的 SHA-256 校验值；原始安装包及校验文件保留。

安装前从托盘菜单退出旧版，再按原安装方式升级。EXE/MSI 附带匹配的 .NET Core/Desktop 10.0.12 运行时。商店版从 Microsoft Store 安装和更新；MSIX 提交包由维护者单独管理，不作为未签名的日常安装下载。

## 使用与兼容性

电脑与音响需处于同一局域网。勾选一只独立音响播放完整立体声；依次勾选两只时分别为 L/R；明确识别的原生配对显示为一个逻辑目标。实时音量默认关闭，可在音量滑条下开启。设置 → 常规可选择外观。

支持 Windows x64，随包运行时要求兼容的 Windows 10 22H2/Windows 11 环境；不提供 Windows 7/8.1 或 ARM64 原生包。接收端固件、访问权限及网络会影响连接和同步，延迟设置不等同于端到端实测延迟。静音保流和既有音频传输策略保持不变。

## What's New

- Added optional real-time volume: when disabled, drag and click ✓ to apply; when enabled, dragging applies automatically. Manual mode remains the default.
- Added system, light and dark appearance with consistent settings cards, native dropdowns, buttons and lightweight transitions.
- Refreshed the app and transparent tray icons; improved refresh controls, EQ alignment, compact layouts and large-text presentation.
- Fixed selection-marker trails after dropdown hover and improved buffered drawing while retaining native selection and keyboard behavior.
- Simplified independent-speaker labels. Empty scans are status messages; unavailable networks, connection failures and interrupted playback still create fault records.
- Refined auxiliary control-channel warning classification without discarding diagnostic log details.
- Fixed an uninitialized ALAC magic-cookie buffer capacity that could cause encoder initialization to fail.
- Retained single-speaker, independent L/R and native-pair routes, EQ, balance, test tones and latency settings.

EXE and MSI include matching .NET 10.0.12 runtimes. Exit the previous version before upgrading. Use Microsoft Store for the Store edition; its MSIX submission is managed separately. Receiver compatibility and latency depend on firmware and network conditions.
