# AirStereo 1.0.7

AirStereo 将 Windows 电脑的系统声音通过局域网发送到兼容 AirPlay / AirPlay 2 的音响。支持单音响完整立体声、两只独立音响 L/R，以及已确认的 Apple 原生立体声对。

## 本版改进

- WinUI 3 Fluent 界面：编译型 XAML、系统材质、系统/浅色/深色主题和中文/英文即时切换。
- 紧凑托盘列表、透明图标和刷新动效；改进高 DPI 布局，修复桌面自动收起、深色闪白和设置窗口关闭后的焦点行为。
- 设置内集成十段竖向峰值均衡器、预设、旁路与左右平衡；移除左右测试音和校准入口。
- 提供 ALAC/PCM、44.1/48 kHz 与延迟选择，连接期间锁定这些设置。
- 中断自动重连支持 1–10 次上限，双独立音响按完整组合恢复。
- 完善启动自动连接、开机静默启动；修复托盘停止播放退出软件，退出时同时关闭设置。
- 优化手动/实时音量，使用 Windows 10 可显示的细线矢量勾选，并修复重复点击后的图标漂移。
- 减少隐藏窗口刷新、设备控件重建和日志更新开销，完善窗口资源释放。
- 诊断日志与故障信息独立显示，保留打开故障文件夹。
- 简体中文 MSI 安装向导支持安装目录选择、1.0.6 升级和正在运行的应用占用处理。

Windows 10 22H2（19045）及以上 x64，包含 Windows 11；内置 .NET 10.0.12 和 Windows App SDK。电脑与音响需同一局域网；48 kHz 能力以接收端协商为准。商店版版本及分发状态以 Microsoft Store 页面为准。

## English

AirStereo streams Windows system audio to compatible AirPlay speakers over a LAN. Version 1.0.7 introduces a compiled WinUI 3 Fluent interface with Chinese/English switching, system/light/dark themes and a compact tray panel. Settings now include a vertical ten-band EQ with presets, encoding/sample-rate selection and optional reconnection limited to 1–10 attempts.

This release improves tray dismissal after using Settings, dark startup rendering, silent startup, reconnect-on-launch, manual/live volume controls and window resource cleanup. The volume check mark is now a vector for Windows 10 compatibility. Stop playback keeps the application running; Exit also closes Settings. Channel test and calibration entries have been removed.

Use the MSI for installation or upgrade from 1.0.6. Its Simplified Chinese wizard supports directory selection and handling a running application. The unsigned MSIX is for Store submission, the Source ZIP matches the release tag, and SHA256SUMS verifies these assets. No EXE installer is included. Requires Windows x64 build 19045 or later; runtimes are included. Receiver negotiation determines 48 kHz compatibility.
